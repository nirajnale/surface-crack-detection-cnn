# 🏗️ CNN-based Surface Crack Detection

A deep learning computer vision project implementing a **Convolutional Neural Network (CNN)** for industrial surface crack detection using **TensorFlow/Keras**.

This project demonstrates a complete deep learning workflow for image classification including:

✅ Image Preprocessing  
✅ Data Augmentation  
✅ CNN Architecture Design  
✅ Batch Normalization  
✅ Dropout Regularization  
✅ Model Training & Evaluation  
✅ Crack Prediction on New Images  

---

# 🧠 Model Architecture

The CNN model consists of:

- Convolutional Layers
- ReLU Activation
- Max Pooling Layers
- Batch Normalization
- Dropout Layers
- Fully Connected Dense Layers
- Softmax/Sigmoid Output Layer

The model is trained to classify images as:

- Crack
- No Crack
